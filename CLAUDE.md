# the.hacken.ing

Small static site served by GitHub Pages at https://the.hacken.ing.

- Repo: github.com/anthonybailey/the.hacken.ing, published from the root of `main`.
- No build step: what is committed is what is served. `.nojekyll` turns off Jekyll processing.
- `CNAME` holds the custom domain; don't delete or rename it, or Pages drops the domain.
- DNS: `the.hacken.ing` is a CNAME record pointing at `anthonybailey.github.io`.
- Deploying = committing to `main` and pushing. Pages goes live about a minute later.
- Preview locally by opening `index.html` in a browser; no server is needed.
- Keep pages self-contained (inline CSS, no external trackers) unless asked otherwise.
